## 📢 Phase 2.3 詳細（外部フィードバック収集）

**目標**: 複数テスターに Stage 1 ビルドを配布し、実際の使用環境でのフィードバックを収集  
**期間**: 2026-03-19～03-23（3-5日）

### 推奨テスター

- **技術的背景**: ゲーム開発経験者（バグ報告可能）
- **人数**: 5 人以上
- **環境**: Windows PC（複数スペックの環境が望ましい）

### 配布内容

```
- Stage1_Build.zip (ビルド本体)
- README_TESTING.txt (操作方法・バグ報告書式)
- Feedback_Form.xlsx (簡易フィードバック記入シート)
```

### 収集すべきフィードバック

| カテゴリ | 項目 | 確認方法 |
|---------|------|--------|
| **進行可能性** | ゲーム開始～クリア可能か | テスト実施 |
| **UI/操作** | ボタン反応・表示の分かりやすさ | 操作テスト |
| **ゲームバランス** | 難易度は Easy/Normal か | プレイテスト |
| **パフォーマンス** | ロード時間・FPS・メモリ | 実測値記入 |
| **グラフィックス** | カメラ角度・表示品質・地形衝突 | ビジュアル確認 |
| **その他の問題** | クラッシュ・エラー・不具合 | ログ・スクリーンショット |

## 🔄 Phase 2.4 詳細（フィードバック対応・最終調整）

**目標**: 外部テスターからのフィードバックに基づくバグ修正・改善、Stage 1 最終版の完成  
**期間**: 2026-03-24～03-28（3-5日）

### 対応優先度

| 優先度 | 種別 | 対応開始 | 完了期限 |
|--------|------|---------|---------|
| **Critical** | 進行不能バグ・クラッシュ | 即座（1-2日以内） | 完了後直ぐ再配布 |
| **High** | UI 改善・パフォーマンス問題 | 3-5 個別対応 | 1-2日 |
| **Medium** | バランス微調整 | その後実施 | 2-3日 |
| **Low** | ドキュメント・UI 微調整 | 最後 | 1日 |

### フィードバック対応アサイン例

```
テスター報告 → 分類（Critical/High/Medium/Low）
     ↓
Critical: 即座に修正・再テスト
     ↓
High: 複数同時対応（並列実装）
     ↓
Medium/Low: 軽微調整
     ↓
統合テスト → 最終ビルド完成
```
