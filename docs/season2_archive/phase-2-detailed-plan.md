## 🎮 各ステージ実装仕様

### **Stage 2: 複数敵タイプ対応（Normal 難易度）**

**目的**: 異なる敵タイプの対応方法学習

```yaml
stage_id: 2
stage_name: "複数の敵"
difficulty: "Normal"
duration_seconds: 900  # 15分
initial_gold: 500
gold_per_wave: 100

# スポーン構成
spawn_point: "north_gate"  # PLATEAU マップの北ゲート地点
waves:
  - wave: 1
    enemy_type: ["slime"]
    count: 10
    interval_sec: 1.0
  - wave: 2
    enemy_type: ["slime", "goblin"]
    count: [8, 5]
    interval_sec: 1.2
  - wave: 3
    enemy_type: ["goblin"]
    count: 10
    interval_sec: 0.8

# ゴール
goal_position: "south_plaza"  # 南広場
goal_damage_limit: 20
goal_victory_condition: "all_waves_cleared"
```

**テスト項目**:
- [ ] スポーン順序が YAML と一致
- [ ] 複数敵タイプの混在状態でのボディ判定正常
- [ ] タワー配置可能エリアが明確
- [ ] ゴール到達可能性確認（敵が詰まらない）
- [ ] ウェーブ間隔でプレイヤーが準備可能な時間確保

### **Stage 3: 複合タワー戦略（Normal 難易度）**

**目的**: 複数タイプのタワーを組み合わせた戦略

**設計方針**: Stage 2 より敵が強化。複数のタワーを組み合わせないとクリア困難

```yaml
stage_id: 3
stage_name: "複雑なマップ"
difficulty: "Normal"
duration_seconds: 1200  # 20分
initial_gold: 600
gold_per_wave: 120

waves:
  - wave: 1
    enemy_type: ["slime"]
    count: 15
    interval_sec: 0.8
  - wave: 2
    enemy_type: ["slime", "goblin", "giant_slime"]
    count: [8, 6, 3]
    interval_sec: 1.0
  - wave: 3
    enemy_type: ["giant_slime"]
    count: 8
    interval_sec: 1.5

goal_damage_limit: 15
```

### **Stage 4: 全敵タイプ出現（Hard 難易度）**

**目的**: 全タイプの敵に対応できるタワー総合戦略

- 敵イパリティ: 最大 4 種類同時出現
- ウェーブ数: 5-6 回
- クリア時間: 20-25 分
- 初期ゴールド: 600（少ない）

### **Stage 5: エクストラ（VeryHard 難易度）**

**目的**: リプレイ性・チャレンジ要素強化

- 特別ルール: 制限時間ボーナス、敵強化モード
- 難易度: 最高
- クリア条件: すべての敵に対応 + ボーナス敵撃破

## 📈 バランス調整テスト計画

### テスト 1: 基本クリア可能性テスト

```
フェーズ: Phase 2.2 実装完了後、本バランス調整前
テスト方法:
  1. 各ステージを 5 回プレイ
  2. クリア / Game Over を記録
  3. クリア成功率を計算

期待値:
  - Stage 1: 80%+ （チュートリアル）
  - Stage 2: 60-70%
  - Stage 3: 60-70%
  - Stage 4: 40-50%
  - Stage 5: 20-30%

NG 基準:
  - クリア成功率が期待値の ±15% 超過 → バランス調整
```

### テスト 2: プレイ時間測定

```
測定項目: 各ステージのプレイ時間
期待値:
  - Stage 1: 8-12 分
  - Stage 2: 10-15 分
  - Stage 3: 12-18 分
  - Stage 4: 15-25 分
  - Stage 5: 20+ 分（エンドコンテンツ）

NG 基準:
  - プレイ時間が期待値の ±3 分超過 → ウェーブタイミング調整
```

### テスト 3: ユニット効率性テスト

```
測定項目: タワーのコスト対効果

テスト方法:
  - 各ステージでそれぞれのタワーのみを使ったプレイテスト
  - 各タワーの「1 ゴールドあたりの敵倒数」を計算

期待値: 全タワーの効率値がおおよそ均等（±20% 以内）

NG 基準:
  - 特定のタワーのみで全ステージクリア可能 → 上位タワーを値上げ
  - 特定のタワーではクリア困難 → 下位タワーを値下げ
```

### テスト 4: 敵難易度テスト（各ステージ）

```
確認項目:
  - 敵の HP が適切か（弱すぎない / 強すぎない）
  - 敵の速度が適切か（鈍すぎ / 速すぎ）
  - 敵の出現ペースはゲーム進行に合致しているか

方法: 戦闘ログから敵の平均生存時間を計算
期待値: 敵 1 体あたり 3-8 秒の生存時間（ステージ難易度で差）

NG 基準:
  - 敵が一撃で倒される → HP 増加
  - 敵がタワーで倒せない → HP 減少
```

## 📝 YAML 仕様書テンプレート

各ステージの YAML ファイルは、以下のテンプレートで統一してください：

```yaml
# Stage N - [ステージ名]
# 難易度: [Easy/Normal/Hard/VeryHard]
# 目的: [学習内容・ゲームコンセプト]

stage_id: N
stage_name: "ステージ名"
map_area: "PLATEAU データセット地点"
difficulty: "Normal"

# ゲーム設定
game_settings:
  duration_seconds: 900
  initial_gold: 500
  gold_per_wave: 100
  goal_damage_limit: 20

# スポーン定義
spawn_config:
  spawn_point: "north_gate"
  spawn_type: "sequential"  # sequential / simultaneous 等

# ウェーブ定義
waves:
  - wave: 1
    enemies:
      - type: "slime"
        count: 10
        spawn_interval_sec: 1.0
        health_modifier: 1.0
        speed_modifier: 1.0
    wave_duration_sec: 10
    wave_end_delay_sec: 15

  - wave: 2
    # ... 以降同様

# ゴール定義
goal_config:
  goal_position: "south_plaza"
  goal_type: "arrival_point"
  victory_condition: "all_waves_cleared"

# 難易度注記
design_notes: |
  - [設計意図]
  - [テスト項目]
  - [既知の制限事項]
```
