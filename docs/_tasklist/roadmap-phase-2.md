## 実装内容詳細

### 2.1: ステージレベルデザイン（20-25人日）

**目標**: チュートリアル→中級→上級への段階的進行設計

#### ステージ構成

| ステージ | 難易度 | 目的 | 工数 | 優先度 |
|---------|--------|------|------|--------|
| **Stage 1** | Easy | タワー配置基本操作 | 3日 | 最高 |
| **Stage 2** | Normal | 複数敵タイプ対応 | 4日 | 最高 |
| **Stage 3** | Normal | 複合タワー戦略 | 4日 | 最高 |
| **Stage 4** | Hard | 全タイプ敵出現 | 5日 | 高 |
| **Stage 5** | VeryHard | リプレイ性強化 | 5日 | 高 |

#### チェックリスト

**すべてのステージで確認**:
- [ ] PLATEAU 地形データとの整合性
- [ ] スポーン点配置の妥当性
- [ ] タワー配置可能エリアの明確化
- [ ] ゴール到達不可能なバグがないか
- [ ] ウェーブ難易度のバランス
- [ ] パフォーマンス測定（FPS 60+ 安定）

**期間**: 20-25日

---

### 2.2: ゲームバランス調整（10-12人日）

**目標**: 難易度の適切な段階化、リプレイ性向上

#### バランス調整項目

| 要素 | 調整内容 | 指標 |
|------|---------|------|
| **ユニット コスト** | タワーのコスト効果比 | 平均プレイ時間 10-15分 |
| **敵難易度** | 敵 HP・速度 | クリア成功率 60-70% |
| **リソース配分** | 初期ゴールド増加率 | 中盤以降の選択肢確保 |
| **ウェーブ構成** | 敵出現パターン | 戦略性確保 |

#### テスト方法

```
1. 各ステージを 10 回プレイ
2. クリア成功率を記録
3. プレイ時間を測定
4. バランス値を調整
5. 再テスト
```

#### チェックリスト

- [ ] Stage 1 クリア成功率 80%+
- [ ] Stage 2-3 クリア成功率 60-70%
- [ ] Stage 4-5 クリア成功率 40-50%
- [ ] 平均プレイ時間 10-15分
- [ ] リプレイ性確保

**期間**: 10-12日

---

### 2.3: カメラ制御の最適化（4-5人日）

**目標**: ゲームプレイを最適化するカメラ動作

#### 実装内容

| カメラ機能 | 実装内容 | 優先度 |
|-----------|---------|--------|
| **初期フレーミング** | ステージ全体を表示 | 最高 |
| **ズーム機能** | マウスホイール対応 | 最高 |
| **パン機能** | ドラッグで画面移動 | 高 |
| **Follow カメラ** | 重要イベント時の追従 | 中 |

#### チェックリスト

- [ ] 初期ビューでステージ全体が見える
- [ ] ズーム範囲 0.5× ～ 2.0×
- [ ] パン速度が適切
- [ ] カメラ遅延なし（60 FPS 維持）

**期間**: 4-5日
