## 実装内容詳細

### 2.0: Stage 1（チュートリアル）コア機能テスト（4-5人日）

**目標**: チュートリアルステージで基本操作・進行可能性を確認  
**優先度**: 最高  
**状態**: 進行中

#### テスト項目

| テスト内容 | 確認項目 | 優先度 |
|-----------|---------|--------|
| **進行可能性** | ゲーム開始～ステージクリアまで進行不能バグなし | 最高 |
| **基本操作** | タワー配置・敵退治・ゴール到達 | 最高 |
| **UI 動作** | ボタン反応・ウィンドウ表示・メニュー遷移 | 最高 |
| **クラッシュ** | 異常終了・NullReferenceException なし | 最高 |

#### チェックリスト

- [x] Stage 1 クリア可能
- [x] UI すべて機能（InfoWindow, MenuButton など）
- [x] ログに Error/Exception なし
- [x] クラッシュ なし

**期間**: 4-5日  
**進捗**: ✅ 完了（2026-02-11）

### 2.1: Stage 1 バグ修正サイクル（3-5人日）

**目標**: Stage 1 テスト中に発見された進行不能バグを修正・ドキュメント化  
**優先度**: 最高  
**実施タイミング**: Phase 2.0 完了後、進行不能バグ発見時に即座に実施

#### バグ修正の流れ

| ステップ | 内容 | 成果物 |
|---------|------|--------|
| **発見** | Stage 1 テストプレイ中に進行不能バグ発見 | バグの概要記録 |
| **分析** | バグの原因・再現手順を特定 | 原因分析ドキュメント |
| **修正** | コード修正・テスト | 修正コミット |
| **ドキュメント化** | unity-design-patterns.md などに追記 | 知識ベース更新 |

#### 対象バグ例

現在までに確認されたバグ：
- OnTriggerEnter/Exit の複数発火による状態不一致 [修正済み]
- Physics.Raycast がトリガーコライダーに引っかかる [修正済み]

#### チェックリスト

- [x] 進行不能バグ 完全解決
- [x] 修正内容を unity-design-patterns.md に記録
- [x] 修正後の Stage 1 クリア可能確認
- [x] ログに新しい Error/Exception なし

**期間**: 3-5日  
**進捗**: ✅ 完了（2026-02-11 - StageGoal/UINotice/static flag fixes）

### 2.3: ゲームバランス調整（10-12人日）

**目標**: 難易度の適切な段階化、リプレイ性向上  
**実施タイミング**: Stage 2-5 実装完了後

#### バランス調整項目

| 要素 | 調整内容 | 指標 |
|------|---------|------|
| **ユニット コスト** | タワーのコスト効果比 | 平均プレイ時間 10-15分 |
| **敵難易度** | 敵 HP・速度 | クリア成功率 60-70% |
| **リソース配分** | 初期ゴールド増加率 | 中盤以降の選択肢確保 |
| **ウェーブ構成** | 敵出現パターン | 戦略性確保 |

#### テスト方法

```
1. 各ステージを 10 回プレイ
2. クリア成功率を記録
3. プレイ時間を測定
4. バランス値を調整
5. 再テスト
```

#### チェックリスト

- [ ] Stage 1 クリア成功率 80%+
- [ ] Stage 2-3 クリア成功率 60-70%
- [ ] Stage 4-5 クリア成功率 40-50%
- [ ] 平均プレイ時間 10-15分
- [ ] リプレイ性確保

**期間**: 10-12日
