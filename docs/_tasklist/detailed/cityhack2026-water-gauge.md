# 水位標（量水標）

高潮で上がった海面の深さを目視で読み取れるようにする設置物。

## テクスチャ

`Assets/Resources/Textures/` に生成済み。

| ファイル | 用途 |
|---------|------|
| `WaterGaugePole.png` | 支柱に貼る目盛り本体 |
| `WaterGaugeBoard.png` | 「想定浸水深」の標識板（支柱の上部に付ける想定） |

### 目盛りの仕様

日本の量水標に倣い、**20cm ごとの紅白帯**と **1m ごとの数字**で構成している。
下端が 0m、上端が 3m。数字は帯の色に応じて白／黒を切り替えて読めるようにしてある。

[IMPORTANT] **縦にタイリングしない**こと。1 枚で全長を覆う前提で、
数字が入っているため繰り返すと目盛りが破綻する。

### 実寸を合わせる

テクスチャは 3m ぶんなので、**支柱の高さを 3m にすると目盛りが実寸と一致**する。
別の長さにするとゲーム内の水深と目盛りがずれるので、
長さを変えるならテクスチャ側の `GAUGE_METERS` を変えて作り直す。

生成コードは `AI_tmp_works/texgen/GenWaterGauge.cs`。
色や帯の間隔を変えたいときはここを直して再生成する
（手順は `AI_tmp_works/texgen/README.md` と同じ）。

## プレファブ要件

**配置場所**: `Assets/Resources/Prefabs/Ornament/watar_Indicator.prefab`

| 項目 | 内容 |
|------|------|
| 支柱 | 高さ 3m の細い直方体。`WaterGaugePole` を貼る |
| 標識板 | 支柱の上部に付ける板。`WaterGaugeBoard` を貼る |
| 原点 | **支柱の下端（0m の位置）をプレファブの原点にする** |
| Collider | 不要（見るだけの設置物） |

[IMPORTANT] 原点を下端にしておかないと、設置時に地面へ合わせても
0m の位置がずれて目盛りが読めなくなる。

[NOTE] マテリアルは HDRP/Lit。Base Map にテクスチャを入れ、
Base Color は白にする（色が乗ると紅白が濁る）。

## 使い方

水面より低い位置に設置すると、水に浸かった高さが目盛りで読める。
海際や低地に何本か立てておくと、潮位が上がる様子が数値として伝わる。
