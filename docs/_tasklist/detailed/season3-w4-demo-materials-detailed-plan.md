## タスク

### Task 1: デモ動画の撮影台本（エージェント・30 分）

3-5 分に収める「見せる順番」を台本化する。撮影の迷いをなくすのが目的。

- [ ] 撮影台本 markdown を作成（docs/game-design/demo-video-script.md）
  - 構成案: タイトル画面 → ステージ選択（三鷹井の頭５丁目＝実在の街） →
    オレンジ予告（ハザードマップを見る） → 防災装置の配置（投資判断） →
    Start Year → 地震（カメラシェイク）→ 倒壊 → 延焼 → 鎮火/自動年終了 →
    結果パネル（無施策時予想との差・ROI） → 2〜3 年目ダイジェスト → 3 年総括
  - 各カットの目安秒数・カメラ操作（TPS/バードビュー切替）・見せたい画面要素を明記
  - 「安定して見せられる」プレイ手順（模範プレイヤーモデルの正解スキーム簡易版）を添える

### Task 2: 首長向け 1 枚スライド構成案（エージェント・30 分）

- [ ] 構成案 markdown を作成（docs/game-design/mayor-slide-draft.md）
  - タイトル / 何ができるか（3 行） / 画面キャプチャ配置案（どのシーンを載せるか）/
    活用シナリオ（住民ワークショップ・防災教育）/ 使用データ（PLATEAU=国交省・実在の街）/
    今後の展開（他地区展開・ワークショップ実施）
  - 行政向けに刺さる要素を優先: 実在の街のデータ・住民参加・投資対効果の可視化

### Task 3: 説明台本（エージェント・Task 2 と同時）

- [ ] 15 秒版: 「何を作ったか」1 文 + 「何が体験できるか」1 文 + 「何に使えるか」1 文
- [ ] 1 分版: 15 秒版 + デモ動画の該当シーンへの誘導を含む進行台本
- [ ] 想定 Q&A を 3-5 件（費用・データ出所・他地区展開・実施形態など）

### Task 4: デモ動画撮影・投稿（ユーザー・1-2 時間）

- [ ] Task 1 の台本に沿ってリハーサル 1 回 → 本番撮影（OBS / QuickTime）
- [ ] YouTube へ投稿（限定公開推奨）、URL をスライドに記載
- [ ] （任意）撮影中に見つかった不具合は notes_season3.md へ記録（修正は W5）

### Task 5: スライド仕上げ（ユーザー・30 分-1 時間）

- [ ] Task 2 の構成案を元に 1 枚スライド化（PowerPoint / PDF）
- [ ] ゲーム画面のスクリーンショットをはめ込み

---

## 進行順序

```
Task 1（撮影台本）→ Task 4（撮影・投稿）        ← 動画が最長リードタイム。先に着手
Task 2+3（スライド構成案・台本）は Task 1 と並行可（エージェントが一括作成）
Task 5（スライド仕上げ）は Task 2 と動画 URL が揃ってから
```

エージェント作業（Task 1-3）は 1 セッションでまとめて完了できる。
ユーザー作業（Task 4-5）が律速のため、台本類を先に渡すことを最優先とする。
