# Season 3 Week 4 詳細計画 - デモ動画 + 首長ミーティング資料

**作成日**: 2026-07-03（同日更新: ミーティング要件の具体化）
**締切**: ミーティングは来週金曜。ユーザーの作業時間を考慮し **水曜までに W4 クローズ**
**スコープ**: W3 で完成したゲーム本体は**現状のまま**使う（見栄え調整・バランス調整は W4 に含めない）

---

## 設計判断の記録（2026-07-03 ヒアリング結果）

| 論点 | 決定 | 理由 |
|------|------|------|
| 締切 | 来週金曜ミーティング → **水曜クローズ** | ユーザーの作業可能時間から逆算 |
| ミーティング形式 | **約 1 時間**。動画でものを見せながら説明し、質疑を受ける形 | 当初想定（30秒説明）から拡大。進行構成（アジェンダ）が必要 |
| 資料の土台 | **既存の GIS 説明・LOD 説明資料**（ユーザー手元）から再構成 | ゼロから作らない。エージェントは再構成の構成案と新規部分（Season 3 の成果）を用意 |
| 出席者 | 首長 + **防災課の同席可能性** | 実務者向けの Q&A（データ出所・延焼モデルの根拠・ハザードマップとの関係・運用）を厚めに準備 |
| 資料の分担 | エージェントは構成案テキスト（markdown）のみ。資料仕上げはユーザー | pptx 生成は不要 |
| 見栄え調整（LongShot 引き・リング視差・CLK 収支・scarcity） | W4 に含めない | 動画は現状の見た目で撮る。調整は W5 以降へ持ち越し |

---

## 成果物（水曜までに揃っているもの）

1. **デモ動画（3-5 分・YouTube 限定公開等）** — ユーザー撮影
2. **ミーティング進行構成（1 時間のアジェンダ）** — 既存 GIS/LOD 資料の差し込み位置を含む再構成案
3. **想定 Q&A 集** — 首長向け（政策・費用・展開）+ 防災課向け（データ・モデルの根拠・実務接続）

---

## タスク

### Task 1: デモ動画の撮影台本（エージェント・30 分）

3-5 分に収める「見せる順番」を台本化する。撮影の迷いをなくすのが目的。

- [ ] 撮影台本 markdown を作成（docs/game-design/demo-video-script.md）
  - 構成案: タイトル画面 → ステージ選択（三鷹井の頭５丁目＝実在の街） →
    オレンジ予告（ハザードマップを見る） → 防災装置の配置（投資判断） →
    Start Year → 地震（カメラシェイク）→ 倒壊 → 延焼 → 鎮火/自動年終了 →
    結果パネル（無施策時予想との差・ROI） → 2〜3 年目ダイジェスト → 3 年総括
  - 各カットの目安秒数・カメラ操作（TPS/バードビュー切替）・見せたい画面要素を明記
  - 「安定して見せられる」プレイ手順（模範プレイヤーモデルの正解スキーム簡易版）を添える

### Task 2: ミーティング進行構成・1 時間アジェンダ（エージェント・30 分）

- [ ] 構成案 markdown を作成（docs/game-design/mayor-meeting-plan.md）
  - 1 時間の時間割: 導入 → 背景（GIS/PLATEAU/LOD ＝**既存資料の差し込みスロット**）→
    Season 3 の成果（デモ動画 + 実演/静止画）→ 活用シナリオ（住民ワークショップ・防災教育）→
    質疑（20 分程度を確保）
  - 既存 GIS/LOD 資料のどこを残しどこを差し替えるかの再構成指針
  - 行政向けに刺さる要素: 実在の街のデータ（国交省 PLATEAU）・住民参加・投資対効果の可視化

### Task 3: 想定 Q&A 集（エージェント・Task 2 と同時）

- [ ] 首長向け: 費用感・他地区展開・ワークショップ実施形態・今後のスケジュール
- [ ] **防災課向け**: データ出所と精度・延焼モデルの根拠と限界（ゲーム的簡略化の明示）・
  既存ハザードマップとの関係（代替ではなく教育補完）・地震/延焼想定の妥当性・実施運用
- [ ] 冒頭 1 分の紹介トーク（自己紹介〜デモに入るまでの導入）

### Task 4: デモ動画撮影・投稿（ユーザー・1-2 時間・月〜水）

- [ ] Task 1 の台本に沿ってリハーサル 1 回 → 本番撮影（OBS / QuickTime）
- [ ] YouTube へ投稿（限定公開推奨）
- [ ] （任意）撮影中に見つかった不具合は notes_season3.md へ記録（修正は W5）

### Task 5: 資料の再構成・仕上げ（ユーザー・水曜まで）

- [ ] 既存 GIS/LOD 資料に Task 2 の構成案を組み込み再構成
- [ ] ゲーム画面のスクリーンショット・動画 URL をはめ込み
