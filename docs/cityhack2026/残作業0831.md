## 本日の作業予定
### プレゼン動画の流れ（予定）
潮位をあげて、街の一部が浸水して壊れる
審査員に他の人同様内水氾濫の可視化だなとおもわせる
地震、火災発生、建物が破壊瓦礫を放出
海から巨大猫が出現して、建物をバラバラに壊していく
審査員にジョーク実装かとおもわせておいてリザルトで、災害瓦礫の推計にも使える実用性をアピールして締め

### 作業内容
- 海面位置初期設定
  ステージyamlの「年に依存しない初期設定イベント」にwatersurface Oceanの基本設定Y座標（ベースライン）を指定できるようにする
- 潮位変動対応
  ステージyamlのタイムラインで潮位がベースラインからいくつ変動するかを指定できるようにする
  event: watersurface # 基礎水面上昇イベント
  value: -6.25  # 水面の高さ（メートル ）  
  海水面の色をyamlからも変更できるようにする。refraction 毒々しく赤などにできるように
- 潮位で水に浸かった建物を破壊にできるような監視を入れる（n秒以上水面よりxCm下に建物のベースラインがあった場合）
- 猫の出現をyears:イベントに移動
- years:イベントに潮位変動対応
- 猫が建物を解体したときのゴミの散乱が地味なので角速度をつけてもっと爆散させたい
