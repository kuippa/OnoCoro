## 5. 発表の内容

京都・舞鶴のマップで、高潮による浸水 → 地震と火災 → 巨大猫による解体 と被害が進み、
最後に**災害廃棄物を可燃・不燃に分けて 4t トラック換算で示す**。

本題は最後の廃棄物推計。動画中の破壊はすべてその数字を出すためのもの。

[NOTE] 巨大猫はジョークに見えるが、**短時間で大量の建物を壊すための装置**という位置づけ。
壊し方が地震でも高潮でも猫でも、廃材の計算は同じであることが要点。
スライドで猫を前面に出しすぎると、企画全体がネタ扱いになるので扱いに注意する。

## 6. スライドに載せる数字と出典

[IMPORTANT] **数字は以下から一字も変えないこと。**
公的資料に準拠していることが企画の説得力の中心にある。

### 発生原単位（床面積あたりの災害廃棄物発生量）

| 建物構造・被害要因 | 原単位 |
|------------------|--------|
| 木造 | 0.6 t/㎡ |
| 非木造 | 1.0 t/㎡ |
| 焼失 | 0.23 t/㎡ |

### 種類別割合（重量比）

| 区分 | 可燃系 | 不燃系 |
|------|-------|-------|
| 木造 | 11.0% | 89.0% |
| 非木造 | 11.0% | 89.0% |
| 焼失 | 0.1% | 99.9% |

可燃系 = 可燃物・柱角材 ／ 不燃系 = 不燃物・コンクリート殻・金属

### 出典

- 国土交通省 PLATEAU 技術資料 `plateau_tech_doc_0015_ver01`
  「5.7 災害廃棄物発生量の採用原単位」
- 発生量の算定は**横浜市災害廃棄物処理計画**に準拠
- 種類別割合は**環境省 災害廃棄物対策指針 技術資料**に準拠
- PDF: https://www.mlit.go.jp/plateau/file/libraries/doc/plateau_tech_doc_0015_ver01.pdf

### その他の数値

- 舞鶴マップの建物数: 約 7,900 棟
- 動画の尺: 180 秒
- ビルドバージョン: v0.0.25-prototype

[NOTE] 焼失の原単位（0.23 t/㎡）は**アプリ側では未実装**。
資料には載っているが、現在は建物構造別のみで判定している。
実装済みのように書かないこと。

## 7. 言い方の制約

[IMPORTANT] 事実と異なる表現をすると質疑で破綻する。以下は必ず守る。

| 項目 | 正しい言い方 |
|------|------------|
| 建物構造 | PLATEAU に構造そのものは**無い**。耐火構造種別・階数・用途地域からの**推定**。「推定」と明記する |
| 可燃・不燃の比率 | **重量比**。コンクリート殻・基礎・土砂が支配的なので、見た目の体積比とは一致しない |
| 廃棄物量 | 原単位は公的資料の値だが、構造推定が入るので**概算**。エリア単位の目安として使う想定 |
| 浸水した建物の廃材 | 現状は倒壊としてのみ計上。水中の瓦礫は描画していない（負荷対策） |
| 他都市への展開 | PLATEAU のデータがあれば動く、という言い方に留める |

## 8. スライド構成案

60 秒しかないので、**多くて 4 枚**。

| # | 内容 |
|---|------|
| 1 | タイトル。プロジェクト名・チーム名・PLATEAU を使っていること |

**「猫はジョークですが、出てくる数字は本物です」**

## 9. プロジェクトの基本情報

| 項目 | 内容 |
|------|------|
| プロジェクト名 | **OnoCoro**（正式名称。`Onokoro` は表記ゆれで、修正中） |
| 概要 | 国土交通省の PLATEAU を使った、まちづくりをテーマにしたゲーム |
| リポジトリ | https://github.com/kuippa/OnoCoro |
| ライセンス | MIT |
| 開発環境 | Unity 6.3.10f1 / HDRP 17.3.0 / PLATEAU SDK |
| 今回のリリース | v0.0.25-prototype（2026-09-03） |

潮位の可視化が注目されている。そこへ「壊したあとに何が残るか」で切り込むのが本企画の立ち位置。

## 11. 表記ルール

このリポジトリの規約（`AGENTS.md`）に合わせる。

- **日本語で書く**
- 絵文字を使わない。強調が要る箇所は `[NOTE]` `[IMPORTANT]` `[WARN]` を使う

  資料側に数字を書く場合は出典とセットにする

- 未実装の機能を実装済みとして書く（特に焼失原単位、津波・土砂災害）
