# デモ動画 撮影台本（3-5 分・首長ミーティング用）

**作成日**: 2026-07-03（W4 Task 1）
**対象ステージ**: 三鷹井の頭５丁目
**方針**: 1 回の通しプレイで「危険を見る → 投資する → 効果が数字で見える」を物語にする。
Year 1 は装置なしで延焼を見せ（問題提起）、Year 2-3 で投資して抑える（解決）という対比構成。

## 撮影の物語構成（対比型）

| 年 | プレイ方針 | 見せたいこと |
|----|-----------|-------------|
| Year 1 | **装置を置かずに** Start | 地震→倒壊→延焼が広がる。「何もしないとこうなる」 |
| Year 2 | オレンジ予告を見て**消火栓を要所に配置** | 延焼が抑えられる。結果パネルの「抑えた延焼」がプラスに |
| Year 3 | 予算内で**消火栓+防火水槽を厚めに配置** | 大地震（本震+余震）でも被害を抑制。ROI が上がる |

※ 通常プレイの推奨（Year1 から置く）とは逆だが、対比が最も伝わる構成。

## カット割り（合計 約 4 分）

### C1: オープニング（0:00-0:25）

- タイトル画面 → ステージ選択で「三鷹井の頭５丁目」を選ぶ
- 開始テロップ「地震火災から街を守ろう（全3年）」が出るまで
- （ナレーション案）「国交省の 3D 都市データ PLATEAU で再現した、実在の住宅地です」

### C2: 危険を見る（0:25-0:55）

- Year 1 配置フェーズ（タイマー停止中）
- **マウスホイールでバードビューへ**：マップ全体とオレンジの建物（倒壊予告）を俯瞰
- （ナレーション案）「オレンジの建物が、地震で倒壊し出火点になる場所。ハザードマップのように危険を見てから、対策を考えます」
- ホイールで TPS に戻す

### C3: Year 1 - 何もしないと（0:55-1:40）

- 装置を置かずに Start Year 1
- 地震（カメラシェイク）→ 倒壊 → 出火 → 延焼で建物が焦げ色になっていく様子
- 鎮火後、自動で結果パネルへ
- **結果パネルをしっかり映す**（地震倒壊 / 火災延焼 / 無施策時の予想延焼 / 投資 0）
- （ナレーション案）「対策をしないと、火は隣の家へ燃え広がります」

### C4: Year 2 - 投資する（1:40-2:40）

- 配置フェーズ：オレンジ予告を確認 → TAB メニューから**消火栓**をビルド → オレンジ付近に配置（2 基程度）
- 効果範囲リングが映るように
- Start Year 2 → 地震 → 出火 → **範囲内の火が消えていく**
- 結果パネル：「抑えた延焼」「投資効果(ROI)」がプラスになっているのを映す
- （ナレーション案）「限られた予算で、どこに防災装置を置くか。投資の効果が数字で返ってきます」

### C5: Year 3 - 大地震に備える（2:40-3:30）

- 配置フェーズ：予告が増えている（本震+余震で 10 棟）→ 防火水槽（広範囲）も追加
- Start Year 3 → 本震 → 余震 → 抑え込み
- 結果パネル → 「総括を見る」

### C6: 総括とクロージング（3:30-4:00）

- 3 年間の総括パネル（累計投資 / 抑えた延焼 / 総合 ROI）を映す
- （ナレーション案）「住民のみなさんと『自分の街の防災投資』を考えるワークショップに使えます」
- タイトルへ戻って終了

## 撮影時の注意

- 各年の火災フェーズは**鎮火で自動終了**するので間延びしない（duration 上限 60-90 秒）
- 地震は Start Year の約 4 秒後、倒壊・出火は約 11 秒後。慌てずカメラを構える
- Year 1 で延焼が物足りない場合はもう 1 テイク（延焼数は run ごとにぶれる）
- 撮影中に見つけた不具合は notes_season3.md へ（修正は W5。撮影は止めない）
