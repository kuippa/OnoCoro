# OnoCoro - プロジェクト概要・目的

**OnoCoro** (オノコロ) は、国土交通省の PLATEAU プロジェクトの 3D 都市モデルを活用した、まちづくりタワーディフェンスゲームです。

---

## プロジェクトの目的

### 主な目標

| 目標 | 説明 |
|------|------|
| **地理情報の可視化** | PLATEAU SDK を使用して、実際の都市データをゲーム内で表現 |
| **教育的価値** | まちづくりやインフラの重要性を楽しみながら学べるゲーム |
| **技術実証** | Unity + PLATEAU SDK の組み合わせによる地理情報ゲームの可能性を探る |
| **オープンソース** | SSD 故障の教訓から、オープンソースでバックアップと知見共有を実現 |

### ターゲットユーザー

[OK] **3 つのターゲット層**:

- タワーディフェンスゲームファン
- 地理情報・都市計画に興味がある人
- PLATEAU SDK を使った開発事例を探している開発者

---

## ゲームコンセプト

### ジャンル

**タワーディフェンスゲーム** - 敵の侵攻を防衛タワーで撃退し、ステージをクリアするゲーム

### 特徴

| 特徴 | 説明 |
|------|------|
| **実際の地理データ** | PLATEAU CityGML データを読み込み、実在の建物・地形をゲーム化 |
| **まちづくり要素** | インフラ配置・リソース管理・都市発展とのバランス |
| **ステージエディタ** | YAML 形式でカスタムステージを作成可能 |

### ゲームプレイフロー

```
ステージ選択
    ↓
[Play フェーズ] ゲーム開始
    - 敵ユニット出現
    - タワーを配置して防衛
    - リソース管理
    ↓
[勝利判定] 全ウェーブ撃退 → ステージ クリア
[敗北判定] ベースダメージ満杯 → Game Over
```

## プロジェクトの非目的（重要）

### [NOTE] 以下を目的としていません

| 非目的 | 理由 |
|--------|------|
| **商業リリース** | 技術実証・オープンソース貢献が主目的 |
| **完全なシミュレーション** | ゲームとしての面白さを優先（GIS ツールではない） |
| **プロフェッショナルな GIS** | PLATEAU SDK の活用事例として位置づけ |
| **リアルなインフラシミュレーション** | ゲーム性・バランスのため適度に簡略化 |

[IMPORTANT] **プロジェクト参加者は この非目的を理解した上で作業してください**

## プロジェクトの背景

### SSD 故障からの復旧プロジェクト

[NOTE] **歴史的背景 - なぜ 2 年の空白があったのか**

#### Timeline

| 年月 | イベント |
|------|---------|
| **2024 年** | OnoCoro 開発中、SSD が物理的に故障 |
| **2024-2025** | 復旧不可能と判断、プロジェクト休止 |
| **2026 年 1 月 1 日** | 2 年前のバックアップを発見・復旧開始 |
| **2026 年 1 月中旬** | オープンソース化決定・GitHub 公開 |

### Recovery フェーズの特性

[WARN] **復旧プロジェクトならではの課題**:

1. **古い参照**: 削除されたファイル・クラスの参照が残存
2. **不完全な状態**: 初期化されていないコンポーネント
3. **データ不整合**: Serialized オブジェクト参照の破損
4. **パフォーマンス未最適化**: 2 年前のコード状態のまま

[RECOMMENDATION] **詳細**: [AGENTS.md - Null チェック](../../AGENTS.md) および [coding-csharp.md](../project-rules/coding-csharp.md) 参照

### オープンソース化の意義

[OK] **同じ悲劇を繰り返さないための戦略**:

```
課題: SSD 故障で 2 年のデータ喪失
    ↓
解決策: Git + GitHub でコード・ドキュメント公開
    ↓
メリット:
  - バージョン管理・歴史追跡可能
  - 分散バックアップ
  - コミュニティからの PR・改善提案
  - プロジェクト継続性の確保
```

## よくある質問（FAQ）

### Q: プロジェクト目的の変更は可能か？

[ANSWER] **いいえ**。プロジェクト目的（PLATEAU SDK 活用・地理情報ゲーム・オープンソース）は固定です。

変更案がある場合は、Issue で提案してください。

### Q: 商業リリースの予定は？

[ANSWER] **現在のところ予定ありません**。Prototype Phase で技術実証を行い、フィードバックに基づいて判断します。

### Q: どのプラットフォームに対応？

[ANSWER] **現在は Windows PC のみ**。将来的に iOS・Android への拡大を検討中です。

### Q: PLATEAU SDK が難しい場合は？

[ANSWER] **PLATEAU 統合は専門的です**。まずは Game Logic・UI 層から貢献してください。[plateau-integration.md](../architecture/plateau-integration.md) で学習可能です。
