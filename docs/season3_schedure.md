## 実装上の注意点

### [OK] 「完璧」は不要
- バグがあってもいい、デモとしてハッピーパスが動けば OK
- プロジェクタで見せなくても、動画デモで十分

### [OK] 物理演算は不要
- ヒートマップは「仮実装」でいい
- 「火が広がる」を完全にシミュレートしなくていい
- 「危険地点が可視化される」で十分

### [OK] Mac での実行
- 動画撮影は簡易版でいい
- ビルド失敗しても、エディタ再生で OK

### [NOTE] Git コミット
- 毎日 1-2 コミット目安
- YouTube ライブで「今晩はこれを実装」と宣言するとやる気が続く
