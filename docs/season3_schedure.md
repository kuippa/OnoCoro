## Week 1: ターンベース化基本実装（夜 3-4h）

**目標**: 既存の敵・タワー・ステージをベースに、「年度」の概念を加える

### Task 1-1: 構造理解（30分）
- [ ] 既存の Enemy/Tower/Stage クラス を読む
- [ ] 現在の敵スポーン・タワー配置フロー確認
- [ ] 「Year 1 → Year 2 への遷移」に必要な変更点をメモ

### Task 1-2: TurnManager/SimulationController 実装（2h）
- [ ] 新クラス作成: `TurnManager.cs` or `SimulationController.cs`
  ```csharp
  namespace CommonsUtility
  {
      internal class SimulationController
      {
          public int CurrentYear { get; set; }
          public void NextYear() { /* Year + 1 */ }
          public void ResetSimulation() { /* Year 1 へ */ }
      }
  }
  ```
- [ ] GameManager に統合
- [ ] PlayMode で Year カウントが正常に動作確認

### Task 1-3: UI に「Year ボタン」追加（1.5h）
- [ ] Canvas に "Next Year" ボタン追加
- [ ] ボタン押下 → NextYear() 呼び出し
- [ ] 画面に "Year ◯" を表示
- [ ] 1回のクリックで Year が正常に進むこと確認

### チェックリスト
- [ ] TurnManager 実装完了
- [ ] PlayMode で Year 1→2→3 が確認できる
- [ ] "Year N" が画面に表示される
- [ ] 敵・タワーは Year 1 と同じ動作

**成果物**: Year カウント + 表示が動く状態

## Week 2: 複数施策 UI + 危険地点ヒートマップ（夜 3-4h）

**目標**: プレイヤーが「どこに何を置くか」を選べるようにする

### Task 2-1: 複数施策の定義（1h）
- [ ] 施策の種類を定義:
  ```
  - 消火栓: コスト 50万、効果 70%、範囲 500m
  - 防火水槽: コスト 30万、効果 60%、範囲 300m
  - 避難広場: コスト 100万、効果 20%、範囲 1000m
  ```
- [ ] `InfrastructureType.cs` に列挙

### Task 2-2: 施策選択 UI（1.5h）
- [ ] Canvas に 3-4個の施策ボタン追加
- [ ] ボタン押下 → 施策が「配置モード」に変わる
- [ ] マップクリック → 施策を配置
- [ ] 配置後の数量表示（「消火栓 ×3」など）

### Task 2-3: ヒートマップ表示（1.5h）
- [ ] Year 開始時、AI が「危険地点」を判定
  - 仮実装: 兼六園の建物密集度から「火が広がりやすい地点」を計算
- [ ] ヒートマップを画面に表示（赤い領域）
- [ ] 参加者が「ここが危険」と視覚的に理解

### チェックリスト
- [ ] 施策ボタンが 3-4個表示される
- [ ] 施策を選択 → マップをクリック → 配置できる
- [ ] ヒートマップが画面に表示される
- [ ] Year をすすめても、ヒートマップが更新される

**成果物**: 施策選択 UI + ヒートマップが表示される状態

## Week 3: 結果表示 + デモ動画（夜 3-4h）

**目標**: ワークショップとして見せられる状態

### Task 3-1: 結果判定ロジック（1.5h）
- [ ] Year 終了時、「施策で火がどこまで止まったか」を計算
  - 仮実装: ヒートマップ領域 × 施策配置で「被害 ◯◯%」を算出
- [ ] ROI 計算: 投資額 vs 被害削減率

### Task 3-2: 結果表示UI（1.5h）
- [ ] Year 終了後、パネルを表示:
  ```
  【Year 1 結果】
  - 被害: 50%
  - 投資: 50万ゴールド
  - ROI: 0.5
  【Year 2 へ続ける or リトライ】
  ```
- [ ] このパネルを見て「地域の脆弱性」を実感できるようにする

### Task 3-3: デモ動画撮影（1h）
- [ ] Mac で OnoCoro を実行（簡易版でも OK）
- [ ] Year 1 → Year 2 の操作を順番に実行
- [ ] 画面を OBS や QuickTime で 3-5分の動画に記録
- [ ] YouTube ライブアーカイブに投稿

### チェックリスト
- [ ] 結果パネルが表示される
- [ ] 被害率 / 投資額 / ROI が表示される
- [ ] 複数年の流れが動画で確認できる
- [ ] YouTube に 3-5分の動画がアップロードされている

**成果物**: 動画デモ（首長打ち合わせで見せられる）

## 実装上の注意点

### [OK] 「完璧」は不要
- バグがあってもいい、デモとしてハッピーパスが動けば OK
- プロジェクタで見せなくても、動画デモで十分

### [OK] 物理演算は不要
- ヒートマップは「仮実装」でいい
- 「火が広がる」を完全にシミュレートしなくていい
- 「危険地点が可視化される」で十分

### [OK] Mac での実行
- 動画撮影は簡易版でいい
- ビルド失敗しても、エディタ再生で OK

### [NOTE] Git コミット
- 毎日 1-2 コミット目安
- YouTube ライブで「今晩はこれを実装」と宣言するとやる気が続く
