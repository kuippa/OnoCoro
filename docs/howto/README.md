# HowTo（作業手順メモ）

**たまにしかやらないので、そのたびに調べ直している作業**の手順を置く。

「前にもやったのに手順を思い出せない」というものを見つけたら、
ここに短くまとめておく。長い解説は不要で、**手順と落とし穴だけ**でよい。

## 一覧

- [import-builtin-assets-to-hdrp.md](import-builtin-assets-to-hdrp.md) -
  アセットストアのモデルを入れてマテリアルがマゼンタになったときの直し方

## 書くときの方針

- 症状 → 原因 → 手順 の順に書く（探している人は症状から入る）
- メニュー名は正確に書く。似た名前の別項目があれば警告を添える
- 実際にやった日付とアセット名を「実績」として残す
  （バージョンが変わって手順が古くなったときの判断材料になる）
